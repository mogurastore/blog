title: vscode のフォントに BIZ UD ゴシックを指定しました
---

今まで vscode のフォントはデフォルトで使っていたのですが markdown で table を作成する際に日本語が混ざっていると表示が揃わなくなるのが気になっていました。

いろいろ調べた結果 BIZ UD ゴシックならきちんと表示が揃うようになるようなので設定してみました。

設定はこんな感じです。BIZ UD ゴシック以外のフォントは vscode のデフォルト設定だったので一応残しました。

```json
"editor.fontFamily": "'BIZ UDゴシック', Consolas, 'Courier New', monospace"
```

なお、等幅フォントなら日本語でも等幅になるとは限らないようで、例えば Cascadia Code などは等幅フォントですが日本語が混じっていると表示がズレてしまいます。

そんなわけで BIZ UD ゴシックを使うようにしたのですが、BIZ UD ゴシックではバックスラッシュが円マークで表示されます。

欲を言えばバックスラッシュのままで表示したいのですが

1. windows で標準的にインストールされている
2. 日本語でも等幅フォント
3. バックスラッシュをそのまま表示

これらすべてを満たすフォントを見つけることができませんでした。

自前でインストールすればもしかしたら可能なフォントもあるかもしれませんが、それは面倒だったのでバックスラッシュの件に関しては妥協することにしました。
