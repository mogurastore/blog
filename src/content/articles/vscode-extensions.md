自分が使っている拡張機能の中でも特におすすめのものを紹介します。

## remote development

[link](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.vscode-remote-extensionpack)

docker, ssh, wsl 経由でファイルを編集できる拡張機能です。

## prettier

[link](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)

コード整形ツール。主に javascript, html, css, yaml, markdown あたりの整形に使います。

## git graph

[link](https://marketplace.visualstudio.com/items?itemName=mhutchie.git-graph)

git の log を見るときに使います。見やすくて気に入ってます。

![](https://github.com/mhutchie/vscode-git-graph/raw/master/resources/demo.gif)

## edamagit

[link](https://marketplace.visualstudio.com/items?itemName=kahole.magit)

emacs の magit インスパイアな拡張機能。log 以外の git 操作はだいたいこれを使っています。

![](https://github.com/kahole/edamagit/raw/5ebf38107c6130cc16a23f18d84aeecc21f09fe8/magit_commit_demo.gif)

## find then jump

[link](https://marketplace.visualstudio.com/items?itemName=tranhl.find-then-jump)

acejump とか EasyMotion っぽいカーソル移動ツール。

![](https://github.com/tranhl/find-then-jump/raw/master/demo/demo.gif?raw=true)
